# Contributing

Thanks for helping improve the Release Readiness Kit. Small, focused changes are welcome.

## Suggested first contribution

Add one practical checklist item to the most appropriate section of `README.md`. For example, improve the guidance for release communication, validation, monitoring, or rollback readiness.

## Workflow

1. Accept the repository collaborator invitation.
2. Create a branch named `docs/add-release-safety-note`.
3. Edit `README.md` and add one useful checklist item.
4. Use the commit message `Add release safety note`.
5. Add the following line to the commit's extended description:

   ```text
   Co-authored-by: Ricky Thakar <102048532+Rickythakar@users.noreply.github.com>
   ```

6. Open a pull request targeting `main`.
7. Leave the pull request open for the repository owner to verify and merge.

Keep the change concise and explain why the new check improves release safety.
