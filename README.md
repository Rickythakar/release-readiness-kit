# Release Readiness Kit

A lightweight set of practical checklists for shipping software with confidence.

## Before release

- [ ] Confirm the release scope and owner
- [ ] Verify automated checks are passing
- [ ] Review configuration and environment changes
- [ ] Confirm rollback steps are documented
- [ ] Prepare customer-facing release notes

## During release

- [ ] Record the deployment start time
- [ ] Monitor application health and error rates
- [ ] Validate the highest-value user journey
- [ ] Keep the rollback decision-maker available

## After release

- [ ] Confirm key metrics remain healthy
- [ ] Share the release outcome with stakeholders
- [ ] Capture follow-up work and lessons learned

These templates are intentionally short. Adapt them to the risk and complexity of each release.
